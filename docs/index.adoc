== About this guide

`planr` is a command-line tool that helps little league organizers set up divisions, teams, and
fields, then generate balanced game, practice, and playoff schedules.

This guide covers the whole workflow: first-time setup, every command, and how the scheduling
algorithms make their decisions. It is written for league organizers who run the tool and for
developers who need to understand its behavior.

The same AsciiDoc sources produce both the HTML and the PDF editions of this guide. See
<<building-docs>> for how to rebuild them.

.Conventions used in this guide
* `planr division add` -- a command you type.
* `<name>` -- a value you supply.
* `[--flag]` -- an optional flag.
* Lines that start with `$` in examples are commands. The lines that follow are the output.
